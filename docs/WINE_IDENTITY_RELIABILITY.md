# 와인 정보 일관성 수정 (2026-09-21)

## 확인된 결함

IMG_5367의 라벨은 Proyecto Cu4tro Bubbles Premium Reserva, Guarda Superior, 2021, Cava이다. 두 결과에서 Proyecto/CU4TRO가 생산자, Guarda Superior가 산지로 들어갔다. 기존 /api/label은 OCR의 역할 분류를 그대로 표시하고 검색으로는 품종만 보완했다. 출처가 없는 기본 정보와 검증한 품종이 같은 화면에 섞였으며, 사용자 간 공통 와인 식별 정보가 없었다.

## 수정

- 라벨 전체 원문을 OCR 결과에 포함하고, 생산자/국가/산지를 라벨에 없는 지식으로 채우지 않도록 제한한다. 품질 용어를 산지로 분류하는 경우를 차단한다.
- 확인한 공통 상품 정보가 있으면 이를 우선한다. 초기 검증 상품은 이 보고의 Cu4tro Premium Reserva 1종이다. 일반 Cu4tro, 로제, 다른 브랜드, 상품명을 잘라낸 사진은 동일 상품으로 강제 연결하지 않는다.
- 미등록 와인은 원문으로 생산자·상품명·산지와 품종을 함께 조사한다. 읽은 자료의 상품별 본문 근거를 검증하고 원래 OCR의 잘못된 생산자를 검색 조건으로 강제하지 않는다.
- 미확정 결과는 이름/연도를 임시 읽기라고 표시하고 생산자·산지를 비워둔다. 기본 정보 출처와 확인 상태를 한/일 표시한다.
- 동일 정규화 라벨 원문·연도의 검증된 검색 결과만 기존 Next Data Cache로 7일 재사용한다. 사진/계정/인증키를 캐시하지 않는다. 실패·미확정 결과는 캐시하지 않는다. DB 변경이나 새 SaaS 없음.

캐시는 모든 서로 다른 촬영을 같은 와인에 연결하는 전역 상품 DB가 아니다. 미등록 와인의 OCR 차이, 동시 최초 요청, 캐시 만료 후에는 여전히 다른 결과가 가능하다. 임의 결과를 정답으로 영구 고정하지 않는다. 전체 상품 일관성을 위해서는 검증된 상품 ID/별칭 카탈로그 확대와 관리자 검수 절차가 후속 과제다. 기존 저장된 노트는 자동 덮어쓰지 않는다.

### 현재 Gemini 연결 실측

2026-09-21 Preview 서버에 저장된 키로 확인했다. 키와 제공사 오류 원문은 출력하지 않았다.

- 모델 목록 조회는 성공했으며 2.5 Flash/Lite와 3.5 Flash-Lite가 목록에 있었다.
- 2.5 Flash와 2.5 Flash-Lite의 검색 요청은 모두 HTTP 404로 실패했다. 목록에 있다는 것만으로 실제 호출 가능성을 보장하지 않는다.
- 검색 없는 짧은 기본 요청에서도 2.5 Flash-Lite는 HTTP 404 / NOT_FOUND였고, 3.5 Flash-Lite는 HTTP 402 / RESOURCE_EXHAUSTED / billing이었다. 검색 도구만의 문제로 단정할 수 없다.
- 현재 연결로 무료 Gemini가 작동한다고 보고할 수 없다. 다른 프로젝트·결제·키 변경은 하지 않았다. 기존 저가 Haiku 대체를 유지한다. 실패 응답에 사용량이 없어 실제 청구액은 확정하지 않는다.
- 진단은 각 커밋 표식이 있는 Preview 빌드에서만 실행했다. 진단 스크립트와 prebuild 훅을 최종 수정본에서 제거하여 일반 빌드에서 API가 호출되지 않게 했다.
