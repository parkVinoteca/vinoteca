# 소믈리에 상세 출력 비교 — 방법

2026-09-22. 운영 서비스는 변경하지 않고, 로그인한 운영자만 호출 가능한 임시 Preview 도구에서 실측했다. Gemini/Claude에 같은 JPEG(긴 변1024px, 품질0.85), 같은 기본 지시문을 사용했다. 파일 저장/테이스팅 기록 생성 없음. 사진별 1회씩, 반복·재시도 없음. 단발 표본이므로 전체 정확도·평균 성능을 보장하지 않는다.

- Gemini: gemini-3.5-flash-lite, 검색 도구 없음, thinking minimal, 최대 출력3000토큰.
- Claude: claude-haiku-4-5-20251001, thinking disabled, 최대 출력3000토큰.
- Claude 검색 포함: 동일 모델/기본 지시, 검색 최대2회, 본문조회 최대1회/5000토큰. 도구가 활성화됐어도 실제 사용 횟수는 응답 usage로 판단.
- 공통 지시: 일본어700~1100자 목표; 이름/연도/생산자/지역/품종/비율/타입/도수/일본가격/외관/향/맛/여운/짧은 코멘트. 불명확한 정보는未確認. 추정 스타일을 명시. 여운의 초 단위 수치, 가짜 출처, 개인 취향 주장 금지.
- 프롬프트 준수 여부도 평가 대상. 지시했다고 모든 답변이 준수하는 것은 아니다. 모델 원문을 확정 정보로 배포하지 않는다.
- 비교는 현재 운영 프롬프트를 그대로 실행한 결과가 아니라 상세 출력 후보의 시험이다. 기존 운영 소믈리에는 설명1문장/특징3개/코멘트2문장 제한이 있다.
- 현재 운영의 개인화 코멘트는 매칭점수65이상/35이하/중간/기록부족 4개 고정 문구. 이번 10가지 문구는 가상의 취향 조건으로 별도 Gemini 호출한 설계 시뮬레이션이며, 실제 사용자 이력을 사용하지 않는다.
- 실시간검색은 Gemini 시험에 포함하지 않았다. 외부 출처 대조는 별도 진행하며 모델에게 정답을 제공하지 않았다.
- API시간은 서버의 providerFetch 구간, 전체요청시간은 브라우저 fetch~JSON완료. 파일선택/압축시간 제외, 운영 Storage업로드 경로와 다르므로 운영화면 전체 대기시간으로 해석하지 않는다.
- API비용은 반환된 토큰/검색횟수의 단가 계산, 청구서 확인 금액 아님. Gemini무료등급0엔; Haiku입력$1/백만, 출력$5/백만, 검색$0.01/회. 엔화는 비교용 $1=¥160 가정(실시간환율 아님), 세금·인프라 별도.
