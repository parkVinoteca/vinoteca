# v1.4.3 평점·회원 정책 (2026-09-27)

구현/로컬 검증 완료. 운영 DB 변경과 배포는 승인 전.

- 개인 평점: 1~5, 0.1 간격. 숫자 버튼과 ± 제거, 5개 눈금과 양끝 안내. 1점이 와인 결함임을 단정하지 않으며 저평가도 취향 분석에 포함한다.
- ラベル写真 위에 AI ON/OFF 토글. ON은 촬영·업로드 후 분석, OFF는 사진만 저장하고 AI 호출/횟수 차감 없음. 수동 입력된 정보는 OFF 사진 첨부 시 유지한다. 한도 없음/조회 불가 시 OFF이며 블라인드에는 표시하지 않는다. 현재 웹 검색은 하지 않으므로 명칭은 「AIでワイン情報を入力」로 한다.
- 무료 출시 정책: 사진 저장·수동 입력 가능, 테이스팅 AI0회, 소믈리에 월3회.
- 유료 출시 정책: 테이스팅 AI월50회, 소믈리에 월20회. AI상한 이후에도 수동 입력·사진 저장 가능.
- 베타: profiles의 실제 plan을 바꾸지 않고 두 플랜의 DB한도를 모두50/20으로 설정한다.
- 새 label_monthly_limit 열로 AI사진 분석과 tasting_monthly_limit(노트 저장)을 분리. 수동 저장 제한은 양쪽NULL 유지.
- 기존 원자적 reserve_ai_usage에서 새 한도를 검사한다. 사용자별 동시요청 잠금, 전역 비용 보호 한도, 10초 연속요청 제한 유지. 단순 클라이언트 차단이 아니다.
- 일본시간 월초 갱신, 이미 기록된 이번 달 label_scan 횟수 그대로 사용. 횟수 초기화/기존 시음 데이터 수정 없음.
- 마이페이지: 현재 베타 설명, 출시 예정 무료/유료 비교, 결제관리 준비 안내. 실제 결제·구독 연결은 없음. 정식 오픈 시 베타 문구 수정과 무료 한도0/3 전환을 별도 승인 후 함께 진행한다.

## 사진·블라인드·아이콘 추가 수정
- 사진 왼쪽 미리보기 / 오른쪽 촬영·업로드 세로 버튼. 사진이 있어도 버튼 위치 유지.
- 블라인드는 향·맛·추론·평점·메모 이후 정답 공개 버튼으로 동일 라벨 편집기를 연다. 블라인드 AI는 공개 후에만 가능하며 테이스팅 AI 한도를 공유한다. AI 정답 타입은 별도 상태로 보관하여 관능 입력을 초기화하지 않는다.
- 새 블라인드 기록의 정답은 wine_name/producer/vintage/country/region/grape_variety와 기존 answer 필드에 함께 저장. mode=blind 및 추론 유지, 중복 일반 기록 생성 없음. 과거 정답 필드만 있는 기록은 셀러 이름 표시에서 fallback. 기존 기록 일괄 변경 없음.
- AppIcon 자체 SVG로 하단5개 메뉴·홈 바로가기/통계·사진 버튼·빈 셀러/블라인드 화면 등을 통일. 외부 이미지/아이콘 의존성 추가 없음.
- 로컬 브라우저에서 정답 공개 전 라벨 미노출, 공개 후 수동 입력, 향 메모·평점 유지 확인. 실제 AI 유료 호출/운영 기록 생성 없음. 390px viewport 가로 넘침 없음.
