# v1.4.3 평점·회원 정책 (2026-09-27)

구현/로컬 검증 완료. 운영 DB 변경과 배포는 승인 전.

- 개인 평점: 1~5, 0.1 간격. 숫자 버튼과 ± 제거, 5개 눈금과 양끝 안내. 1점이 와인 결함임을 단정하지 않으며 저평가도 취향 분석에 포함한다.
- 무료 출시 정책: 사진 저장·수동 입력 가능, 테이스팅 AI0회, 소믈리에 월3회.
- 유료 출시 정책: 테이스팅 AI월50회, 소믈리에 월20회. AI상한 이후에도 수동 입력·사진 저장 가능.
- 베타: profiles의 실제 plan을 바꾸지 않고 두 플랜의 DB한도를 모두50/20으로 설정한다.
- 새 label_monthly_limit 열로 AI사진 분석과 tasting_monthly_limit(노트 저장)을 분리. 수동 저장 제한은 양쪽NULL 유지.
- 기존 원자적 reserve_ai_usage에서 새 한도를 검사한다. 사용자별 동시요청 잠금, 전역 비용 보호 한도, 10초 연속요청 제한 유지. 단순 클라이언트 차단이 아니다.
- 일본시간 월초 갱신, 이미 기록된 이번 달 label_scan 횟수 그대로 사용. 횟수 초기화/기존 시음 데이터 수정 없음.
- 마이페이지: 현재 베타 설명, 출시 예정 무료/유료 비교, 결제관리 준비 안내. 실제 결제·구독 연결은 없음. 정식 오픈 시 베타 문구 수정과 무료 한도0/3 전환을 별도 승인 후 함께 진행한다.
