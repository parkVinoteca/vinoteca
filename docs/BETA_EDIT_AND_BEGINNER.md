# 베타 기록 수정·사용량 (2026-09-28, 운영 미적용)

- 마이와인 상세 → 수정: 기존 테이스팅 폼으로 본인 기록을 갱신한다. 일반/블라인드, 사진, 평점, 향, 메모를 유지한다.
- beta migration: 월 한도 NULL = 무제한. 요청 로그는 계속 저장한다. API 제공사 한도는 별개이며 유료 서비스 자동 가입/전환은 없다.
- 일본 시간 하루 100회부터 사용자·날짜별 관리자 알림을 갱신한다. 차단하지 않는다. 마이페이지를 열 때 조회하며 이메일/푸시 발송은 없다. 관리자 UUID를 확인 후 별도 승인으로 등록해야 한다.
- 운영 적용에는 migration/RLS/관리자 지정 및 배포 승인이 필요하다. 정식 출시 전에 free 0/3, paid 50/20 월 한도를 복구한다.

## 초간단 입력 (2026-09-28 추가, 운영 미적용)

일본어 이름은「ひとこと記録」, 한국어는「초간단 기록」. 와인명/사진과 기존 공통 5점 평점(0.1 단위), 장소·메모를 중심으로 한다. 색·향 강도·산미 등 전문적 판단은 요구하지 않는다. 모르는 감각 항목은 비워 두고 AI가 대신 채우지 않는다. 모드를 바꿔도 기존 입력은 유지한다. 다시 마실 의향 항목은 후속 검토 사항이다.

세 모드 및 블라인드에 「飲んだ場所 / 와인을 마신 곳」 선택 자유입력을 공유한다. 최대 200자, 예: 自宅 / ワインショップ〇〇. `drinking_place` 별도 컬럼으로 저장하며 기존 기록은 NULL 유지, 기존 소유자 RLS 적용. 마이와인 상세 표시 및 수정 지원. `20260928_drinking_place.sql` 운영 적용은 승인 대기.
