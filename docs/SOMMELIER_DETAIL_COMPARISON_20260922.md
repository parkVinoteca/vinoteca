# AI 소믈리에 상세 출력·비용 비교

2026-09-22 · 사진 API 시험 9회 + 코멘트 시험 2회 · 운영 변경 없음

**요청한 분량의 설명은 Gemini 3.5 Flash-Lite 무료 API로 가능했습니다.** 이번 3종에서는 약 3.3~4.2초에 상세 답변을 만들었고, Claude가 일관되게 우수하지는 않았습니다. 다만 긴 답변이 모두 정확한 것은 아닙니다.

## 현재 출력이 짧은 이유

운영 프롬프트는 설명 1문장, 특징 최대 3개, 소믈리에 코멘트 최대 2문장으로 제한합니다. 개인 취향 문구는 매칭 점수에 따라 4개의 고정 문구를 선택합니다. 이번에는 상세 출력용 새 지시문을 사용했습니다. 현재 운영 화면의 결과를 그대로 비교한 시험은 아닙니다.

## 시간과 비용

같은 사진 전체를 1024px JPEG로 압축해 같은 기본 지시문을 전달했습니다. 각 조건을 1회씩 실행했습니다. 아래 시간은 모델 API 응답 시간이며, 비용은 반환된 사용량으로 계산했습니다.

| 사진 | Gemini · 검색 없음 | Claude · 검색 없음 | Claude · 검색 도구 포함 |
|---|---:|---:|---:|
| Domaine de l'Enclos Chablis 2022 | 4.189초 / ¥0 | 11.616초 / 약 ¥0.97 | 14.112초 / 약 ¥7.39 |
| Capannelle Solare 2013 | 3.962초 / ¥0 | 9.845초 / 약 ¥0.82 | 15.081초 / 약 ¥7.74 |
| Tortue & Grue | 3.316초 / ¥0 | 6.841초 / 약 ¥0.66 | 4.998초 / 약 ¥0.97 |

- Claude 모델: `claude-haiku-4-5-20251001`, 현재 운영과 동일한 모델입니다.
- 검색 도구 포함 조건에서 샤블리·Solare는 각각 검색 2회, Tortue는 실제 검색 0회였습니다. 본문 조회는 모두 0회였습니다.
- 브라우저 요청~응답 완료는 Gemini 5.20~7.20초, Claude 검색 없음 9.08~14.48초, 검색 도구 포함 7.31~17.63초였습니다.
- 사진 선택·압축 시간은 제외했습니다. 이번 도구는 운영의 Storage 업로드를 거치지 않으므로 운영 전체 대기 시간과 동일하지 않습니다.
- 실제 Gemini 출력 길이는 샤블리 1,064자, Solare 1,055자, Tortue 968자였습니다. Markdown 포함입니다. Tortue는 정보 부족을 설명한 분량이며, 풍미를 확인했다는 뜻이 아닙니다.

**추가 Claude 비용 합계: $0.115970, 약 18.56엔.** 무료 Gemini의 사진·코멘트 시험은 무료 등급 내 0엔입니다. 청구서 확인 금액이 아니며, 환율은 비교용 $1=¥160 가정입니다. 세금·인프라 비용은 별도입니다.

단가: Haiku 입력 $1/백만 토큰, 출력 $5/백만 토큰, 검색 $0.01/회. Gemini 동일 모델의 유료 단가는 입력 $0.30/백만, 출력 $2.50/백만입니다. [Google 공식 요금](https://ai.google.dev/gemini-api/docs/pricing), [Anthropic 공식 요금](https://platform.claude.com/docs/en/about-claude/pricing).

이번 사진 3회의 토큰을 Gemini 유료 단가에 대입하면 평균 약 **0.28엔/회, 월 20회 약 5.65엔**입니다. 검색 비용은 없는 조건이며, 유료 Gemini를 실제 호출하거나 결제를 전환한 결과는 아닙니다. 검색 2회를 사용한 Claude 2종은 평균 약 7.57엔이므로, 매번 같은 수준으로 월 20회 검색한다면 약 151.36엔입니다. 작은 표본의 예시이며 550엔 요금제의 수익을 보장하지 않습니다.

## 정확도와 문장 품질

| 사진 | Gemini · 검색 없음 | Claude · 검색 없음 | Claude · 검색 포함 |

| Tortue | 이름·T&G 브랜드 보존. 실제 양조장·국가·품종·향미는 미확인, 뒷라벨 요청 | Fortue & Grui로 오독. T&G를 producer에 배치하고 병색에서 화이트로 추정 | 이름 오독 유지. 검색은 실행하지 않고 뒷라벨 요청으로 종료 |

3종 단발 시험이므로 모델 전체의 우열로 일반화하지 않습니다. 모든 사진 호출은 HTTP 200/정상 종료였지만, 정확도 합격 9회라는 뜻은 아닙니다.

대조 근거: [Capannelle 공식 제품](https://web.capannelle.it/en/solare/)은 Toscana IGT, Sangiovese 80%/Malvasia Nera 20%, 일반 제품 도수 13%를 기재합니다. [2013 시음 자료](https://www.jamesmagazine.it/james-tasting/solare-2013-capannelle/)도 80/20을 기재하지만 도수는 없습니다. Claude가 제시한 14.5%를 확정값으로 채택하면 안 됩니다. [Domaine 공식 제품](https://www.domainedelenclos.fr/copie-de-les-vins), [수입사 제품](https://www.tedwardwines.com/products/chablis-2022)은 제품명과 기본 특징 대조에 사용했습니다. 수입사 URL은 2022지만 현재 SKU는 23으로 보여 URL만으로 빈티지를 확정하지 않았습니다.

## 권장 설계

1. 상세 설명은 Gemini로 생성하고 기본 정보·예상 향미·개인 취향 판단을 분리합니다.
2. 색·주요 향·숙성 향·바디·산도·당도·탄닌·여운을 구조화된 항목으로 받아 일관되게 표시합니다. 추정 표시는 앱이 붙입니다.
3. 여운의 초 단위 수치는 측정하지 않았으므로 생성하지 않습니다. 도수·가격·정확한 비율은 뒷라벨 또는 해당 빈티지 출처로 확인합니다.
4. 추가 검색에는 Gemini가 읽은 이름·생산자·연도와 미확인 항목만 전달합니다. 사진을 처음부터 다시 읽게 하지 않습니다.
5. 취향은 최근 기록·상대적인 호불호·비슷한 스타일의 기록 수·반대 근거를 짧게 요약해 같은 Gemini 요청에 포함합니다.
6. 일본어 출력, 현재 날짜, 추정 표현을 검사합니다. 보관 상태를 모르면서 시음 적기를 단정하지 않습니다.

이번 작업은 비교·설계 검토입니다. 운영 API나 화면은 교체하지 않았습니다. 임시 비교 UI/API는 시험 후 최신 Preview 소스에서 제거했습니다.
