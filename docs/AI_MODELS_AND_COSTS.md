공식 출처: [Google 요금](https://ai.google.dev/gemini-api/docs/pricing), [Anthropic 요금](https://platform.claude.com/docs/en/about-claude/pricing).

무료 Gemini API는 실제 프로젝트 무료한도가 있을 때만 무료다. API 키를 코드에서 다른 문자열로 바꾼다고 자동으로 유료전환되는 것은 아니며 Google 프로젝트의 결제설정이 필요하다. 이번 작업에서는 Google 결제계정/카드/키를 변경하지 않는다.

## 실제 확인한 Gemini 상태

2026-09-20 승인된 Preview 실측에서 현재 저장된 Gemini 키가 3회 모두 `provider_billing`(제공사 결제 관련 거절)으로 분류되었다. 당시에는 프로젝트 목록 오류로 원인을 확인하지 못했다. 원문/키를 공개하지 않는다.

2026-09-21 내부 브라우저 재확인: 회사 계정으로 AI Studio와 프로젝트 목록에 정상 접근했다. 표시된 Default Gemini Project와 My First Project 모두 `Tier 1・前払い` 및 `クレジットなし`였다. 두 프로젝트가 연결된 결제 화면에서 `クレジット残高 ￥0`, `オートチャージ: オフ`, 서비스 계속 이용을 위한 크레딧 구매 안내를 확인했다. 선불 잔액 0 상태는 실제 API의 결제 거절과 일치한다. 현재 Vercel 키와 이 프로젝트의 직접 대응은 키를 열람하지 않고 아직 대조하지 못했으므로, 모든 오류의 원인을 확정하지는 않는다. 카드 자체 잔액 부족으로 확인된 것은 아니다.

회사 이메일이라서 무료 API가 일괄 금지된다는 근거는 없다. [Google 공식 Workspace 안내](https://ai.google.dev/gemini-api/docs/workspace?hl=ja)는 Workspace의 AI Studio 기본 접근을 지원한다. [공식 결제 안내](https://ai.google.dev/gemini-api/docs/billing)에 따른 프로젝트 이용 등급·결제 상태와 조직 정책을 구분한다.

개인 Gmail 로그인 후 확인: 새 Default Gemini Project는 `無料枠`, 결제 계정 없음, 기본 API 키 존재. 그러나 레이트 제한 화면에서 `権限が拒否されました`가 표시되어 실제 할당량은 확인하지 못했다. 신규 계정이므로 정상화될 것이라고 추정하지 않는다. Vercel의 `codex/verified-wine-identity` Preview 브랜치에만 `GEMINI_API_KEY` Secret을 추가할 폼을 준비하고 사용자 직접 입력·저장을 요청했다. 값은 열람하지 않았다. 실제 API 호출 비교는 키 저장 후 진행하며 현재 무료 동작 성공으로 보고하지 않는다. 결제·자동충전·운영 연결 변경 없음.

## 중단을 줄이는 방법

### 개인 무료 프로젝트 실제 호출 비교 (2026-09-21)

사용자가 Preview 브랜치 전용 키를 직접 저장했고, Vercel의 적용 범위가 `codex/verified-wine-identity`임을 확인했다. 운영 키는 변경하지 않았다. 같은 Preview 서버에서 3.5 Flash-Lite 기본 텍스트 요청은 HTTP 200, 1.289초(입력3/출력2토큰)로 성공했다. Google Search를 켠 요청은 HTTP 429 / RESOURCE_EXHAUSTED, 2.5 Flash-Lite는 기본·검색 모두 HTTP 404였다. 검색이 무료로 가능하다고 판단할 수 없으며 429의 세부 한도 사유는 확정하지 않았다. 사진 정확도나 실제 이미지 요청은 이 작은 텍스트 시험으로 검증되지 않는다.

결과: 회사 이메일 일반 제한이 입증된 것이 아니라, 선불 잔액 0인 회사 프로젝트와 무료 개인 프로젝트의 기본 호출 가능 여부가 달랐다. 현재 무료 키는 Preview만 사용한다. 실제 사진 확인에는 Preview 로그인 허용 주소 추가 승인이 남아 있다. 진단 스크립트와 빌드 훅은 결과 확인 후 제거했다. 원자료: `docs/measurements/free-gemini-20260921.json`.

Gemini 한도·결제·일시 장애 시 같은 요청 안에서 저렴한 유료Haiku로 한 번 자동 대체. 최근 한도/결제거절은 같은 서버에서5분간 Gemini를 건너뛴다. 새 서버에서는 다시 확인될 수 있다. 두 제공사가 동시에 실패하거나 자체비용안전한도에 도달하면 오류는 가능하며 무중단을 보장하지 않는다.
미확인 정보와 사진인식 실패는 추측으로 채우지 않는다. 무제한 재시도나 고급Sonnet 자동전환 없음. Google잔여한도를 미리 예측해 자동결제를 켜는 시스템은 아님.

## 베타 이용 한도

모든 기존/신규 회원에게 수동테이스팅기록 무제한, AI소믈리에 월20회(일본시간), 하루최대20회. 실제 계정의 free/paid 값은 유지해 정식출시 때 구분 가능. 이용내역 리셋 없음. 사진분석의 월300회/일50회 및 프로젝트전체 월소믈리에500회·라벨2000회의 비용안전제한은 유지한다. 실패한 시작요청도 기존대로 횟수에 포함한다.

마지막 소믈리에 3건 모두 응답은 성공했지만 품종 확인은 Mouton Cadet만 통과했고 다른 2건은 원문 근거 검증을 통과하지 못해 숨겼다. 일본가격도 1건만 표시됐다. 노트의 Mouton Cadet 품종은 Cabernet Sauvignon, Merlot, Cabernet Franc로 확인됐다. Palmer 노트는 원문의 C.Sauvignon 약어를 인식하지 못한 문제를 회귀테스트로 수정했으며 수정 후 추가 유료 호출은 하지 않았다. HTTP 성공과 모든 정보 확보는 다르다.

이번 반복 개발검증에서 사용량이 반환된 호출의 합계는 약 **$1.314 / 210엔**. 실패호출 중 사용량 미반환분은 제외하고 실제 청구서는 확인하지 않았다. 원자료: `measurements/affordable-ai-20260920.json`. 자동 빌드 유료검증 훅은 제거했다.

## 범위와 다음 개선

휴대폰 촬영·반사·흔들림·업로드 시간은 이번 합성라벨 실측에 포함되지 않는다. Gemini 프로젝트 목록을 확인할 수 없어 무료 잔여량을 미리 경고하는 기능은 구현하지 못했다. 현재는 같은 사용자 요청 안에서 오류를 감지해 Haiku로 대체한다.
운영 로그에는 제공사별 소요시간·토큰·검색횟수만 기록해 비용을 추적한다. 사진/질문/키/사용자정보는 기록하지 않는다. 반복되는 와인 정보의 검증된 캐시가 다음 비용절감 우선순위이며 이번 배포에는 포함하지 않았다.

## v1.3.2 Preview 재검증 (2026-09-21)

현재 수정본은 PR #10이며 아직 운영 반영 전이다. 라벨의 역할 오분류를 바로잡고, 검증된 공통 상품 자료와 7일 검색 캐시를 추가했다. 초기 검수 상품은 Proyecto Cu4tro Cava Premium Reserva 1종이다. 이 상품은 사진 읽기 이후 유료 웹검색을 생략한다. 미등록 상품은 생산자·산지·품종까지 함께 검증하므로, 이전의 '품종이 사진에 있으면 검색하지 않음'과 비용 조건이 다르다. 새 흐름의 실제 평균 비용은 아직 측정하지 않았다.

현재 키로 Gemini 모델 목록 조회는 성공했지만, 실제 검색 호출은 2.5 Flash/Lite 모두 404였다. 검색 없는 기본 요청도 2.5 Flash-Lite는 404, 3.5 Flash-Lite는 402 결제 관련 거절이었다. 무료 Gemini API 정상 이용이나 잔여 무료 한도는 확인하지 못했다. 현재 자동 Haiku 대체를 유지하고 결제·키 설정은 변경하지 않았다. 자세한 공식 요금표와 검증 결과는 [와인 정보 검증 문서](WINE_IDENTITY_RELIABILITY.md)를 참고한다. 모델 목록과 실제 호출 가능 여부는 별개다.
