# Vinoteca — AI 모델·비용 노트

갱신: 2026-09-21 · v1.3.2 · PR #10. 사용자가 새 무료 프로젝트의 Gemini 키를 Production에 직접 저장했고 Vercel의 저장 성공을 확인했다. 운영 적용은 PR #10의 배포 결과를 기준으로 한다.

## 현재 무료·유료 구분

| 기능 | 모델/처리 | 현재 비용 |
|---|---|---|
| 테이스팅 사진 읽기 | Gemini 3.5 Flash-Lite, 새 무료 프로젝트 | 무료 할당량 안에서 입력·출력 0엔 |
| 검수 상품 정보 연결 | 검증된 공통 자료 | 추가 AI 검색 비용 없음 |
| 검증된 검색 결과 재사용 | 7일 캐시 | 캐시 적중 시 추가 AI 검색 비용 없음 |
| 미등록 와인 정보·품종 조사 | Claude Haiku 4.5 | 유료: 토큰 + 검색 비용 |
| Gemini 제한·장애 시 사진 읽기 대체 | Claude Haiku 4.5, 최대 1회 | 유료: 이미지 입력·출력 토큰 |
| AI 소믈리에 | Claude Haiku 4.5, 검색 최대 2회 | 기존과 동일하게 유료 |

**테이스팅 전체와 AI 소믈리에가 모두 무료로 바뀐 것은 아니다.** 무료 Gemini 웹검색은 실제 호출에서429 제한 오류였다. 사진 읽기를 무료화하고 검증된 자료를 재사용해 검색 비용을 줄이는 구성이다. 초기 검수 상품은 Proyecto Cu4tro Cava Premium Reserva 1종이며 모든 와인에 적용되는 공통 DB는 아니다.

## 계정 문제였는가?

회사 이메일 자체의 금지가 확인된 것은 아니다. 회사 계정은 AI Studio에 정상 접근했다. 표시된 두 프로젝트 모두 유료 선불 등급이며 연결 결제 계정은 잔액0엔·자동충전 꺼짐이었다. 기존 키의 결제 관련 거절과 일치한다. 카드 자체의 잔액 부족을 확인한 것은 아니다.

새 개인 계정의 프로젝트는 무료 등급이고 결제 계정이 없었다. 이 키로 기본 호출과 실제 사진 읽기가 성공했다. 확인된 차이는 **프로젝트의 이용 등급·결제 상태와 실제 호출 결과**다. Gmail로 바꾸면 항상 해결된다는 의미는 아니다. 무료 한도 화면은 권한 오류로 잔여량을 확인하지 못했다.

공식 근거: [Workspace 이용](https://ai.google.dev/gemini-api/docs/workspace?hl=ja), [결제·등급](https://ai.google.dev/gemini-api/docs/billing).

## 실제 사진 검증

2026-09-21 제공된 Cu4tro 병 사진을 전체 이미지와 라벨 크롭으로 분석했다. 두 번 모두 동일한 상품명, Clos Montblanc, 2021, Catalunya, Spain, Macabeo / Xarel·lo / Parellada / Chardonnay가 나왔다. 2021년 정확한 비율은 미확인으로 안내했다.

| 사진 | 제공사 | 모델 응답 시간 | 입력 / 출력 토큰 | 추가 유료 검색 |
|---|---|---:|---:|---|
| 전체 사진 | Gemini | 1.842초 | 1,249 / 110 | 없음 |
| 라벨 크롭 | Gemini | 1.493초 | 1,277 / 108 | 없음 |

무료 프로젝트에서 처리됐으며 청구서를 확인한 금액 실측은 아니다. 업로드·전체 UI 대기 시간 제외. 이번 상품은 검수 자료와 일치해서 검색을 생략했다. 일반 와인 전체의 평균 시간·비용·정확도를 보장하지 않는다.

기본 텍스트 호출은1.289초에 성공. 3.5 Flash-Lite 검색429, 2.5 Flash-Lite 기본·검색404. [원자료](measurements/free-gemini-20260921.json). 임시 진단 스크립트와 빌드 훅은 제거했다.

## 한도와 장애 대응

베타 회원 수동 기록 무제한, 소믈리에 월20회·하루20회. 사진 분석 월300회·하루50회, 프로젝트 전체 월 소믈리에500회·라벨2000회 안전한도 유지. 실패한 시작 요청도 횟수에 포함된다.

Gemini 제한·장애 시 유료 Haiku로 한 번 대체한다. 두 제공사 장애나 앱 자체 한도까지 무중단을 보장하지 않는다. 무료 잔여량을 미리 읽어 자동 결제를 켜는 기능은 없다.

제공사별 토큰·검색 횟수로 비용을 추적하며 키·사진·사용자 질문은 로그에 남기지 않는다. 다음 과제는 검수 상품 확대와 미등록 상품 검색 성공률·평균 비용 측정이다.
