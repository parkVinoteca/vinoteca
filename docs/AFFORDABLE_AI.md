# v1.3.1 저비용 분석과 유료 소믈리에 월20회

2026-09-20 사용자 요청. 구현/오프라인검증 완료. 운영배포와 SQL 적용은 별도 승인 전. 새 유료 실측은 수행하지 않았다.

## 구현
- 사진의 실제 글자: 기존 Gemini3.5 Flash-Lite 유지, 출력1024토큰. 30초 제공사 안전제한. Gemini할당량/결제거절 때 Sonnet으로 자동 전환하던 경로 삭제. 무료 Gemini가 계속429이면 사진인식이 실패하므로 운영 적용 전에 프로젝트할당량 확인 또는 유료Gemini 소액운영 승인이 필요하다. 새 키를 만들거나 결제를 켜지 않았다.
- 누락된 품종: Haiku4.5(claude-haiku-4-5-20251001), 검색1회/문서읽기1회/문서2000토큰/출력1600토큰. 기존 동일와인·빈티지·문서인용 검증 유지. 품종이 라벨에 있으면 검색하지 않음. 문서제한은 근사치이고 PDF/검색결과 전체입력 비용의 절대상한은 아니다. 1개자료만 읽으므로 이전보다 품종확인율이 낮아질 수 있다. 실패하면 식별결과를 유지하고 품종검색미완료 안내.
- 소믈리에: Haiku4.5, 검색1회/출력1600토큰. 짧은 와인설명·특징3개·한마디·일본가격 중심. USD 추가검색 제거. 확인된 URL없는 가격·비율·한마디 제거 유지. 이미지입력/구조추정/개인화 기능 유지. 고급모델 재시도 없음.
- 전문가점수 OFF 유지. 사용자 관찰값에 AI추정치 자동저장 없음.
- 10초 강제종료 없음. 한국어/일본어 분석화면에 정확한 분석을 위한 확인작업이 오래 걸릴 수 있음을 명시. 기존 업로드/분석/정리 상태와 취소 유지. 장애시 무한대기를 피하는 기존 서버/브라우저 안전제한 유지.
- 신규 SQL은 paid의 월소믈리에50→20만 변경. free5회, 기록수정, RLS, 사용자실사용내역 변경 없음. 결제연동 전 계정은 무료로 남음. 실패한 시작요청도 기존대로 회수에 포함됨. 20회는 성공20회를 보증하는 정책이 아님.

## 비용 가정 (실측 아님)
환율160엔/USD. Haiku 표준 입력$1/100만·출력$5/100만, 검색1회$0.01. 캐시/세금/환전수수료 제외.

| 소믈리에 실제청구 입력토큰 가정 | 출력800토큰+검색1회 비용 | 월20회 |
|---|---:|---:|
|10,000|3.84엔|76.80엔|
|30,000|7.04엔|140.80엔|
|50,000|10.24엔|204.80엔|

출력上限1600까지 사용하면 표보다 건당0.64엔/월20회12.8엔 추가. 검색결과 입력량은 공급자가 정하므로 이 표는 단가민감도이며 실제금액 보장 아님. Sonnet실측5만토큰을 Haiku에 그대로 적용해도 모델요금은 반으로 줄지만 검색1회전환에 따른 정확도/토큰 감소는 실측이 필요하다.

예시: 세전/결제비용차감후476.35엔, 유료100명·기본인프라월7200엔이면72엔/명. 테이스팅검색도 건당입력2만+출력800+검색1회라고 보수적으로 가정해30건=163.2엔, 사진읽기30건=6.48엔. 소믈리에20건 입력3만 가정140.8엔을 빼면93.87엔/명. 무료회원/인건비/광고/초과저장/환불 전 잔액이며 순이익이 아니다. 사진에서 품종을 읽어 검색을 생략할수록 내려간다. 무료회원과 유료회원이 공유하는 프로젝트500회소믈리에/2000회라벨 안전제한은 유지. 상업출시 전에 유료규모/비용예산과 함께 조정해야 한다.
