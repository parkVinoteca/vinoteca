## 결정

사용자가 결과를 확인하고 **자동 점수 검색 끄기**를 선택했다. 라벨에 이미 품종이 있으면 검색을 생략한다. 품종을 모르면 기존 품종 검색만 수행한다. 수동 WS/WA/JS 입력은 계속 없으며 과거 미검증 점수도 표시하지 않는다. 새 AI소믈리에 한마디는 기존 소믈리에 응답 안에서 생성하고 별도 AI 요청/검색을 추가하지 않는다(답변 길이만큼 출력 토큰은 늘 수 있음).

측정용 자동 빌드 훅은 제거했다. 스크립트는 명시적인 `--run-paid-benchmark` 인수 없이 실행되지 않으며 결과를 공개사이트에 배포하지 않는다. 다시 실행하려면 별도 비용 승인을 확인한다.
